# 🛋️ Furnixar E-Commerce Platform

A modern, full-stack furniture e-commerce platform built with React, NestJS, and MongoDB.

## 📋 Project Overview

**Timeline:** 1 Month Development  
**Status:** Frontend Complete, Backend & Admin Panel In Progress

### 🏗️ Architecture

```
furnixar-ecommerce/
├── frontend/          # React SPA (Vercel)
├── backend/           # NestJS API (MongoDB)
├── admin-panel/       # Admin Dashboard
└── docs/             # Documentation
```

## 🚀 Features

### Frontend (React)
- ✅ 6 Homepage Variations
- ✅ Full E-commerce Flow (Cart → Checkout → Payment)
- ✅ User Authentication & Profiles
- ✅ Product Catalog with Filtering
- ✅ Blog & Portfolio Sections
- ✅ Responsive Design (Tailwind CSS)
- ✅ Deployed on Vercel

### Backend (NestJS + MongoDB)
- 🔄 In Development
- User Management
- Product Management
- Order Processing
- Payment Integration

### Admin Panel
- 🔄 Planned
- Dashboard Analytics
- Product Management
- Order Management
- User Management

## 🛠️ Tech Stack

| Component | Technology | Deployment |
|-----------|------------|------------|
| Frontend | React 19 + Vite + Tailwind CSS | Vercel (Free) |

## 📦 Installation & Setup

### Prerequisites
- Node.js 18+
- MongoDB (local or Atlas)
- Git

### Quick Start

```bash
# Clone the repository
git clone https://github.com/awaisfreelancing2026-source/furnixar-ecommerce.git
cd furnixar-ecommerce

# Frontend Setup
cd frontend
npm install
npm run dev

# Backend Setup (Coming Soon)
cd ../backend
npm install
npm run start:dev
```
